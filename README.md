# homebrew-tap

Homebrew formulae for gherlein projects.

```sh
brew tap gherlein/tap
brew install skills-mapper   # installs sm and ms
brew install gogl            # installs gogl
```

| Formula | Installs | Source |
| --- | --- | --- |
| `skills-mapper` | `sm`, `ms` | <https://github.com/gherlein/sm> |
| `gogl` | `gogl` | <https://github.com/gherlein/gogl> |

Formulae are published here by GoReleaser on each tagged release.
