# homebrew-tap

Homebrew formulae for gherlein projects.

```sh
brew tap gherlein/tap
brew trust gherlein/tap    # Homebrew refuses to load formulae from an untrusted tap
brew install skills-mapper
```

| Formula | Installs | Source |
| --- | --- | --- |
| `skills-mapper` | `sm` and `ms` | <https://github.com/gherlein/sm> |

Formulae are published here by GoReleaser on each tagged release.
